# Knowledge index

Cross-thread reference material — schemas, domain facts, lookup tables,
long-term documents. Files live in `files/`; one line each below.

`memory.md` holds cross-thread memory — grep it, don't read it whole.

## Files

- `files/feedback.md` — the running log of everything Chris says about how the
  business and the software work. Append-only, logged as it arrives. The raw
  material for everything else.
- `files/business/` — the working picture of how LPS actually runs: operations,
  people, seasons, recurring friction. Living documents, revised in place.
- `files/requirements/` — what crystallizes out of the log: one file per change
  worth making, with its route and status, plus `index.md` (the backlog).

All three are the `feedback-loop` skill's; it owns their formats.
