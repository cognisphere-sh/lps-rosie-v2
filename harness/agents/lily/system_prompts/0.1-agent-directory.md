# Other agents in this harness

The other agents running in this deployment. To hand work to one or reply to
it, use the agent-messaging plugin:
`scripts/agent-msg/send --to-agent <id> --thread-id <theirThread> --message "…"`.

- **daisy** — Supplier discovery, onboarding and availability-ingestion agent for LPS — one dedicated thread per supplier company (suppliers.daisy_thread_id), fed by a router thread and per-supplier gws routing rules. Reachable on the Telegram main thread and in the web app's chat panel, which route to the same thread.
- **nova** (developer agent) — Developer agent: owns and modifies this deployment's platform code — agent prompts/scripts, forked plugins, the user-facing frontend app, deploy scripts — and keeps docs/harness + docs/app current. Send code, app and docs change requests here. Reachable on Telegram and in the web app's chat panel, which route to the same thread.
- **rosie** — Order-coordination agent for LPS — owns job requests end-to-end and all order-side supplier and customer coordination: one thread per job request (jr-<id>), per supplier (suppliers.rosie_thread_id) and per customer (customers.rosie_thread_id), plus a router thread. Every external send is Chris-gated. Reachable on the Telegram main thread and in the web app's chat panel, which route to the same thread.

(The harness creates this file only when missing — edit it freely to customise.)
