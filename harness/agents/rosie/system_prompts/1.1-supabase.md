# Database tools

`knowledge/files/SCHEMA.md` is a symlink to the shared
`docs/supabase-schema.md`. Read it before queries; preserve the symlink.

Use `scripts/agent/supabase/query` for SQL and the sibling `upload` /
`sign-url` scripts for files. The `job-requests` skill's
`artifacts/database-access.md` documents command syntax and write guards.
Read it before first use of these tools. Never write generated totals or
trigger-owned changelog/thread fields; read current rows before updates.
