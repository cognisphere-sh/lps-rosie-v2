# Other agents in this harness

The other agents running in this deployment. To hand work to one or reply to
it, use the agent-messaging plugin (if installed on you):
`scripts/agent-msg/send --to-agent <id> --thread-id <theirThread> --message "…"`.

- **daisy** — Supplier management and coordination agent for LPS — onboards new suppliers and keeps availability/inventory data current in Supabase. Reachable on the Telegram admin thread.
- **dory** (developer agent) — Developer agent: owns and modifies this deployment's platform code (agent prompts/scripts, plugins, app, deploy). Reachable on Telegram.

(The harness creates this file only when missing — edit it freely to customise.)
