# Other agents in this harness

The other agents running in this deployment. To hand work to one or reply to
it, use the agent-messaging plugin:
`scripts/agent-msg/send --to-agent <id> --thread-id <theirThread> --message "…"`.

- **nova** (developer agent) — Developer agent: owns and modifies this deployment's platform code — agent prompts/scripts, forked plugins, the user-facing frontend app, deploy scripts — and keeps docs/harness + docs/app current. Send code, app and docs change requests here. Reachable on Telegram and in the web app's chat panel, which route to the same thread.
- **rosie** — Customer-success agent for LPS — owns customers and job requests in Supabase: intake, sourcing coordination (via daisy), pricing, quotes and status. Never contacts suppliers directly; emails customers only with Chris's explicit approval. Reachable on the Telegram main thread and in the web app's chat panel, which route to the same thread.

(The harness creates this file only when missing — edit it freely to customise.)
