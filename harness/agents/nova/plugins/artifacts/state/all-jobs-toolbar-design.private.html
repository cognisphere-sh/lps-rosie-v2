Try the layout

  • Tap statuses independently. Select all and Deselect all are different states. Clear all returns to Availability + Committed.
  • Open Filters to see Created and Updated. Desktop also has all seven Item statuses; phone keeps Customer inside Filters and leaves Item status out, as it does today.
  • The Filters badge counts only nested Item-status/date deviations. Primary statuses and Customer do not add to it. An Item-status subset or none counts once; all seven counts zero.

Both views share demo selections. There are no job rows or live results. Search is a layout-only field; it does not run a search. New job request and Expand all are disabled placeholders.
